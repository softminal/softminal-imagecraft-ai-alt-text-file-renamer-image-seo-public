# Vue Tailwind Dashboard Plugin

## Description
The Vue Tailwind Dashboard Plugin is a WordPress plugin that integrates Vue 3 with Tailwind CSS using Vite for building a modern dashboard interface. This plugin allows developers to create dynamic and responsive user interfaces within the WordPress ecosystem.

## Features
- Integration of Vue 3 for reactive components.
- Utilization of Tailwind CSS for styling.
- Built with Vite for fast development and build processes.
- Custom API handling through WordPress.

## Installation
1. Clone the repository or download the plugin files.
2. Place the `vue-tailwind-dashboard-plugin` folder in the `wp-content/plugins` directory of your WordPress installation.
3. Activate the plugin from the WordPress admin dashboard.

## Usage
Once activated, the plugin will automatically enqueue the necessary scripts and styles. You can start building your Vue components in the `src/components` directory and customize your styles in `src/styles/tailwind.css`.

## Development
To start developing the plugin:
1. Navigate to the plugin directory.
2. Run `npm install` to install the required dependencies.
3. Use `npm run dev` to start the development server with Vite.
