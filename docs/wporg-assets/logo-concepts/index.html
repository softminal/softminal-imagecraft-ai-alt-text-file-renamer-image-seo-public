ImageCraft · identity

Six marks, judged where they actually live

A logo for this plugin has to survive 20 pixels of monochrome in the WordPress admin sidebar long before anyone sees it at full size. Every concept below is shown at all three real sizes — and dropped into a live-accurate admin menu — so the choice is made on evidence, not on how it looks blown up.

Where it appears
Admin menu icon, plugin navbar, WordPress.org listing
Hard constraint
Menu icon renders monochrome via currentColor
Palette
Brand blue → teal, matching the SEO and Performance pillars
01

Ascend

Recommended

One line that reads as a mountain range and a rising chart at the same time — the plugin's two jobs in a single stroke. It is the only concept here that says image and ranking together, and a stroked path with round joins stays crisp at 16px where filled detail turns to mush.

03

Aperture

A three-blade iris — photographic, precise, and the most premium-feeling mark of the six. The trade-off is meaning: an aperture says camera, and this plugin never takes a photo. It also holds the least detail at 16px, where the blades start to close up.

04

Stack

Three cascading tiles — literally what the plugin now produces: the original, plus its WebP and AVIF copies. Technical, modern, and unlike anything else in the image-optimizer category. The risk is legibility of meaning: without context it could be any "layers" icon.

06

Monogram

An I and a C, set as pure geometry. The most brand-forward option and the only one that couldn't belong to any other plugin — it behaves like a company mark rather than an icon. It also carries no meaning on its own, so it needs the wordmark beside it to do any work.

Where I'd land

Ascend (01) — it is the only mark that carries both halves of the product in one stroke, it is the most legible of the six at 16px, and it reads as a deliberate mark rather than a stock image glyph. Stack (04) is the interesting runner-up if you want to lean into the technical, format-conversion story.

Once you pick one, the swap touches three places:

  • includes/Menu.php — the inline base64 SVG menu icon (use the mono file)
  • resources/images/imagecraft-logo.png — the navbar lockup, regenerated as mark + wordmark
  • WordPress.org assets — icon-256x256.png, icon-128x128.png, and the banner

All twelve files are already in docs/wporg-assets/logo-concepts/ — six colour marks and six monochrome menu icons, as editable SVG.
