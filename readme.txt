== Description ==

Make your WordPress site accessible with AI-generated alt text. This plugin helps you automatically generate descriptive alt text for all your images using AI.

**100% Free Forever**

This plugin is completely free with no paid tiers or hidden costs. You use your own API key from Anthropic, OpenAI, or Google Gemini, giving you full control and unlimited usage.

**Features**

* Scan your entire media library
* Generate alt text for all images at once
* Auto-generate for new uploads
* Multiple tone options (Professional, Casual, Technical, SEO)
* Edit alt text before accepting
* Batch processing with progress tracking
* Detailed usage statistics

**Easy Setup (3 Minutes)**

1. Install the plugin
2. Get a free API key from Anthropic, OpenAI, or Google Gemini
3. Add credits to your API account
4. Start generating alt text

**Cost**

The plugin itself is free. You only pay for API usage:
* Anthropic Claude: ~$0.0008 per image
* OpenAI GPT-4: ~$0.01 per image
* Google Gemini: ~$0.001 per image

**Privacy & Security**

* API keys stored encrypted in your database
* No data sent to third parties (except AI providers)
* All processing happens on your server
* GDPR compliant

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/smart-alt-text-ai/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Follow the setup wizard to add your API key
4. Start generating alt text!

== Frequently Asked Questions ==

= Is this really free? =

Yes! The plugin is 100% free with no paid tiers. You only pay for API usage to Anthropic, OpenAI, or Google Gemini.

= Which AI provider should I choose? =

We recommend Anthropic Claude for the best quality at the lowest cost. OpenAI and Google Gemini are also great options.

Yes. Your API key is encrypted and stored securely in your WordPress database.
